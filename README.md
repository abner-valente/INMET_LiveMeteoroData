# Projeto de obtensão de dados meteorológicos do INMET

## Objetivo
1. Criar uma webscraping para obtenção de dados do site do INMET -> [https://tempo.inmet.gov.br/TabelaEstacoes]
2. Tratar e padronizar os dados para criação informação meteorológica em cima geodados.

- Python 3.14.0
